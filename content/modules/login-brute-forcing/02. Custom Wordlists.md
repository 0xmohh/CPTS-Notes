Generic wordlists (rockyou, SecLists) get you a baseline. Custom wordlists get you the win — especially against corporate targets where the password is `<CompanyName><Year>!` and no public dump contains it.

## Username Enumeration First

Every valid username you confirm cuts the attack surface. Sources:

- **SMB null sessions** — `enum4linux -U target`, `rpcclient -U "" -N target` → `enumdomusers`
- **LDAP anonymous bind** — `ldapsearch -x -H ldap://target -b "dc=corp,dc=local"`
- **Kerberos user enum** — `kerbrute userenum users.txt --dc target`
- **SMTP VRFY / EXPN** — if the mail server allows it
- **Web error oracles** — "user not found" vs "wrong password" reveals validity
- **OSINT** — LinkedIn, GitHub, breached dumps. Scrape names, run through `username-anarchy`.

### username-anarchy — Permute Real Names

```bash
git clone https://github.com/urbanadventurer/username-anarchy
./username-anarchy Jane Smith > jane_smith.txt
./username-anarchy --input-file names.txt > corp_users.txt
```

Produces `jsmith`, `jane.smith`, `smithj`, `janes`, etc. — standard corp username formats.

## Site-Themed Passwords with CeWL

CeWL spiders a target site and extracts unique words. Perfect for building a themed wordlist against a corp login portal.

```bash
# Depth 2, min word length 5, save to file
cewl -d 2 -m 5 -w company.wordlist https://corp.example.com

# With basic auth
cewl -a --auth-type Basic --auth-user admin --auth-pass pw -w list.txt https://target
```

Combine with hashcat rules to mutate (`Companyname` → `Companyname123`, `C0mp4nyn4m3!`, etc).

## Mutating with Hashcat Rules

Small wordlist + good ruleset > huge wordlist.

```bash
# best64 — 64 common mutations
hashcat --stdout -r /usr/share/hashcat/rules/best64.rule base.txt > mutated.txt

# OneRuleToRuleThemAll — massive, high-yield
hashcat --stdout -r OneRuleToRuleThemAll.rule base.txt > big.txt

# Stack multiple rules
hashcat --stdout -r best64.rule -r toggles1.rule base.txt > stacked.txt
```

> [!tip] Rule-based mutation is cheap and effective
> A 1000-word themed list + best64 = 64,000 candidates — almost all plausible. The same 64,000 pulled from rockyou is mostly garbage for a targeted attack.

## crunch — Mask / Charset Generation

Use when you know the password format (length, character set).

```bash
# All 6-char lowercase
crunch 6 6 abcdefghijklmnopqrstuvwxyz -o out.txt

# 8-char alphanumeric, fixed pattern
crunch 8 8 -t Pass@%%% -o patterns.txt    # Pass@ + 3 digits

# With permutation chars: @=lower, ,=upper, %=digit, ^=special
crunch 10 10 -t ,,,,@@@%%% -o out.txt
```

> [!warning] Crunch wordlists explode fast
> `crunch 8 8 abc...z0..9` is ~2.8 TB. Pipe directly into the brute-forcer with `--stdout` style flows, or constrain with a pattern.

## CUPP — Personalised Wordlists from OSINT

For a specific user. Feed it OSINT: names, DOBs, pet names, interests.

```bash
sudo apt install cupp -y
cupp -i    # interactive prompt
```

CUPP permutes the inputs with years, leetspeak, special-char suffixes. Output is typically 10k-100k candidates — small enough to brute even against rate-limited services.

## Common Combo Recipes

### Corp AD Spray
```bash
# Username list from username-anarchy on LinkedIn-scraped names
# Password list: seasons + years + common separators
echo -e "Spring2024!\nSummer2024!\nAutumn2024!\nWinter2024!\nSpring2025!\nSummer2025!" > spray.txt
```

### Vendor Default Creds
```bash
# SecLists has curated default-cred lists per product
ls /usr/share/seclists/Passwords/Default-Credentials/
```

### Combine Lists Without Dupes
```bash
cat list1.txt list2.txt | awk '!seen[$0]++' > combined.txt
```
