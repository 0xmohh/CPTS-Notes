## Cheatsheet

### Burp Hotkeys
```
CTRL+R           Send request to Repeater
CTRL+SHIFT+R     Jump to Repeater tab
CTRL+I           Send request to Intruder
CTRL+SHIFT+I     Jump to Intruder tab
CTRL+U           URL-encode selection
CTRL+SHIFT+U     URL-decode selection
CTRL+B           Base64-encode selection
```

### ZAP Hotkeys
```
CTRL+B           Toggle request interception (break)
CTRL+R           Open Replacer
CTRL+E           Open Encoder/Decoder/Hash
```

### Default Proxy Listener
```
127.0.0.1:8080   # Burp and ZAP default
```

### CA Certificate Install
```
Burp:  http://burp → CA Certificate → Firefox about:preferences#privacy → View Certificates → Authorities → Import
ZAP:   Tools > Options > Network > Server Certificates > Save → import same way
```

### Burp Intruder Attack Types
```
Sniper          1 payload set, 1 position at a time — single-field fuzz
Battering Ram   1 payload set, same value in ALL positions simultaneously
Pitchfork       N payload sets, 1:1 parallel (user[0]+pass[0], user[1]+pass[1])
Cluster Bomb    N payload sets, full Cartesian product — credential stuffing
```

### Intruder Grep Match (common flags)
```
200 OK                 # directory/file discovery
Welcome                # successful login
Invalid password       # negative — invert logic to find valid users
SQL syntax             # SQLi error-based detection
Set-Cookie             # session issued
```

### Burp Match & Replace Rule (User-Agent)
```
Type:    Request header
Match:   ^User-Agent.*$
Replace: User-Agent: HackTheBox Agent 1.0
Regex:   true
```

### Burp Match & Replace Rule (Response body)
```
Type:    Response body
Match:   type="number"
Replace: type="text"
```

### Common Filter Patterns
```
MIME:        HTML, Script, XML, JSON, CSS, Images, Flash, Other text, Other binary
Status:      2xx (success), 3xx (redirect), 4xx (request error), 5xx (server error)
Scope:       Show only in-scope items — set after adding target
```

### Proxychains for CLI Tools
```
# /etc/proxychains.conf (last line)
http 127.0.0.1 8080

proxychains -q curl http://TARGET/
proxychains -q nikto -h http://TARGET/
```

### Metasploit Proxy Routing
```
set PROXIES HTTP:127.0.0.1:8080
```

### ZAP Spider vs AJAX Spider
```
Spider          Static link crawling — fast, misses JS-rendered routes
AJAX Spider     Headless browser — follows XHR / SPA routes, slower
```

### Scan Configurations (Burp)
```
Crawl strategy - fastest           # quick sitemap build
Crawl limit - 10 minutes           # bounded crawl
Audit checks - critical issues only # RCE/SQLi/SSRF focus
Audit checks - passive             # no payloads sent
```

### Severity / Confidence Priority
```
High + Certain/Firm   → verify immediately, likely exploitable
High + Tentative      → manual verification required
Medium/Low            → batch for report, review for chains
Informational         → context, usually report-only
```

## Checklist

### Initial Setup
- [ ] Launch Burp or ZAP, confirm listener on `127.0.0.1:8080`
- [ ] Install CA cert in Firefox (Authorities tab, trust for websites)
- [ ] Configure FoxyProxy with `Burp` / `ZAP` entries
- [ ] Verify HTTPS traffic flows without cert warnings
- [ ] Open the pre-configured browser for a sanity check

### Scoping
- [ ] Add target host(s) to scope via right-click `Add to scope`
- [ ] Set tool to restrict operations to in-scope items only
- [ ] Add dangerous paths (logout, delete, password reset) to exclusions
- [ ] For ZAP: confirm target is in Default Context before scanning

### Intercept Workflow
- [ ] Turn intercept on, browse to the function under test
- [ ] Forward noise until your target request arrives
- [ ] Inspect multipart bodies, cookies, custom headers
- [ ] Send interesting requests to Repeater (`CTRL+R`) or Intruder (`CTRL+I`)
- [ ] Enable response interception only when you need to edit HTML/JS

### Match & Replace / Replacer
- [ ] Set a custom `User-Agent` (`HackTheBox Agent 1.0`) if target filters on UA
- [ ] Convert `type="number"` → `type="text"` to bypass client-side validation
- [ ] Unhide hidden form fields (Burp: Response modification rules)

### Intruder / Fuzzer
- [ ] Pick the right attack type (Sniper for single field, Cluster Bomb for creds)
- [ ] Mark payload positions with `§` (Burp) or Add fuzz location (ZAP)
- [ ] Load wordlist (SecLists for Burp, built-in File Fuzzers for ZAP)
- [ ] Disable URL-encoding when fuzzing extensions or raw bytes
- [ ] Add Grep Match string to flag interesting responses
- [ ] Sort results by Status, Length, or Grep column
- [ ] In Burp Community, keep lists small — 1 req/sec throttle
- [ ] In ZAP, bump concurrent threads to 20 for speed

### Scanner Workflow
- [ ] Add target to scope before scanning
- [ ] Run Crawl / Spider first to build the site map
- [ ] For SPAs, also run ZAP AJAX Spider
- [ ] Provide auth credentials or record a login macro where possible
- [ ] Run Passive Scan to pick low-hanging issues (headers, cookies)
- [ ] Run Active Scan with `critical issues only` for speed, or full audit for depth
- [ ] Filter issues by `High` + `Certain/Firm` first
- [ ] Manually verify every scanner finding before reporting

### Repeater / Request Editor
- [ ] Send interesting request to Repeater
- [ ] Toggle request method (GET ↔ POST) via right-click
- [ ] URL-encode payloads before sending (`CTRL+U` in Burp)
- [ ] Use Inspector / Encoder tab for base64 / hex / URL transforms
- [ ] Compare Original vs Edited request panes (Burp)

### Proxying Other Tools
- [ ] Set `proxychains` to route CLI tools through `127.0.0.1:8080`
- [ ] For Metasploit: `set PROXIES HTTP:127.0.0.1:8080`
- [ ] For curl: `curl -x http://127.0.0.1:8080 ...`
- [ ] For Python requests: `proxies={"http": "...", "https": "..."}`
- [ ] Remember: proxying slows tools — only enable when debugging

### Reporting
- [ ] Export findings from Burp (`Target > Site map > Issue > Report issues`)
- [ ] Export ZAP report via `Report > Generate HTML Report`
- [ ] Treat scanner output as appendix data — never as the deliverable
