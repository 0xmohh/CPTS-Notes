title: Proxy Setup & Fundamentals

Burp Suite and OWASP ZAP are the workhorses of web pentesting. Both sit between your browser and the target, letting you intercept, inspect, modify, and replay every request. Pick one based on the engagement — Burp Pro if you have the license, ZAP when you need unthrottled fuzzing or an open-source tool. In practice you want to be fluent in both.

## Burp vs ZAP

| Feature | Burp Community | Burp Pro | ZAP |
|---|---|---|---|
| Intercept / Repeater / Decoder | ✅ | ✅ | ✅ |
| Fuzzer / Intruder | Throttled (1 req/s) | Full speed | Full speed |
| Scanner | ❌ | ✅ (best in class) | ✅ |
| Extensions | BApp Store (limited) | Full BApp Store | ZAP Marketplace |
| Price | Free | Paid | Free |

> [!tip] Switch between them freely
> Both tools default to `127.0.0.1:8080`. Only one proxy can bind the port at a time — stop one before starting the other, or change the listener port.

## Pre-Configured Browser

The fastest way to get going. Both tools ship a Chromium-based browser with the proxy and CA cert already wired up.

- Burp: `Proxy > Intercept > Open Browser`
- ZAP: Firefox icon at the end of the top toolbar

For quick tests this is enough. For real engagements you'll usually want to proxy your own Firefox.

## Firefox + FoxyProxy

To route real Firefox through Burp/ZAP:

1. Install the [FoxyProxy](https://addons.mozilla.org/en-US/firefox/addon/foxyproxy-standard/) extension
2. Add a profile: `127.0.0.1`, port `8080`, name it `Burp` or `ZAP`
3. Click the FoxyProxy icon → select the profile when you want traffic proxied

This lets you flip in and out of the proxy per browsing session — critical because proxied browsing is noisy and slow for normal use.

## CA Certificate Install

Without the proxy's CA cert, Firefox will throw errors on every HTTPS request. Install it once:

**Burp cert:** With Burp selected in FoxyProxy, visit `http://burp` → click `CA Certificate` to download.

**ZAP cert:** `Tools > Options > Network > Server Certificates` → `Save`.

**Import into Firefox:**
1. `about:preferences#privacy` → scroll to `Certificates` → `View Certificates`
2. `Authorities` tab → `Import` → select the downloaded `.der` / `.cer` file
3. Check `Trust this CA to identify websites` → OK

> [!warning] Never install the proxy CA on a daily-driver browser profile
> Anyone who steals your laptop (or malware on it) can MITM all your HTTPS. Keep a dedicated pentest profile.

## Changing the Listener Port

If `8080` is taken:
- Burp: `Proxy > Proxy settings > Proxy listeners`
- ZAP: `Tools > Options > Network > Local Servers/Proxies`

Update FoxyProxy to match or you'll get connection refused errors.

## Intercepting Requests

### Burp

`Proxy > Intercept` → click `Intercept is on/off`. Browse the target, flip back to Burp, you'll see the request held. `Forward` sends it, `Drop` kills it, `Action > Send to Repeater` (or `CTRL+R`) stashes a copy for replay.

### ZAP

Click the green/red break button in the top bar or press `CTRL+B`. Intercepted requests appear in the top-right pane. Click the step button to forward.

ZAP's HUD overlays controls inside the pre-configured browser itself — you can intercept, scan, and view history without leaving the page.

> [!tip] Forward the noise, catch the signal
> The browser makes dozens of background requests (telemetry, favicons, CDN assets). When intercepting, hammer `Forward` until you see your actual target request. Or set scope first and only intercept in-scope traffic.

## Intercepting Responses

Sometimes the server sends you an HTML form with `type="number"` or disabled fields, and you want to loosen it up before it renders.

**Burp:** `Proxy > Proxy settings` → enable `Intercept Response` under `Response interception rules`. Forward the request, then edit the response HTML (e.g. `type="number"` → `type="text"`, `maxlength="3"` → `maxlength="100"`).

**ZAP:** After intercepting a request, click `Step` — ZAP automatically holds the response for edit.

Response edits only last for that one page load. For persistent changes use Match and Replace rules.

## Match & Replace (Burp) / Replacer (ZAP)

Automatic request/response rewriting. Set once, apply to every matching request.

**Burp rule example — override User-Agent:**
```
Type:    Request header
Match:   ^User-Agent.*$
Replace: User-Agent: HackTheBox Agent 1.0
Regex:   true
```

**ZAP Replacer** (`CTRL+R`) does the same thing. Pick `Request Header (will add if not present)`, match on `User-Agent`, replace with your value.

**Persistent response rewrite — enable all input fields:**
```
Type:    Response body
Match:   type="number"
Replace: type="text"
```

Now every page load gets the rewrite without manual intervention. This is how you "patch" the client-side of the app for an entire session.

## HTTP History

Every request that flows through the proxy is logged.

- Burp: `Proxy > HTTP history`
- ZAP: `History` tab at the bottom, or the HUD history pane

Filter by status, MIME type, URL path, or (Burp) by scope. Right-click any entry to send to Repeater, Intruder, or Scanner.

> [!note] Burp shows Original vs Edited requests
> If you modified a request on the fly, Burp's history keeps both versions. Click the request header in the detail pane to switch views. ZAP only logs the final sent request.

## Repeater / Request Editor

Where you spend half your engagement. Replays requests with manual edits.

**Burp:** `CTRL+R` sends the selected request to Repeater. `CTRL+SHIFT+R` jumps there. Edit anything, hit `Send`, read the response. Right-click → `Change Request Method` flips GET ↔ POST for free.

**ZAP:** Right-click a request → `Open/Resend with Request Editor`. Same workflow. You can also replay via the HUD's `Replay in Console` or `Replay in Browser`.

## Encoding / Decoding

Payloads often need encoding before the server will accept them. Both tools bundle encoders:

- URL-encode: Burp `CTRL+U`, ZAP auto-encodes request bodies
- Base64, Hex, HTML entities, Unicode: Burp `Decoder` tab or Inspector; ZAP Encoder/Decoder/Hash (`CTRL+E`)

Characters that typically need URL-encoding in request bodies:
- Space (otherwise ends parameter value)
- `&` (parameter delimiter)
- `#` (fragment identifier)
- `+`, `=`, `/`, `?`, `%`

> [!tip] Chain encodings in Burp Decoder
> Drop a string in, decode as base64, then decode the output again as URL. The output pane lets you stack transforms without copy-paste.

## Proxying Non-Browser Tools

Anything that speaks HTTP can route through your proxy — `curl`, `ffuf`, Nmap scripts, Metasploit modules, custom Python. Point them at `127.0.0.1:8080`.

**Proxychains** (easiest for CLI tools):
```bash
# /etc/proxychains.conf — comment out old socks, add:
http 127.0.0.1 8080

proxychains -q curl http://TARGET/
```

**Metasploit:**
```
msf6 > set PROXIES HTTP:127.0.0.1:8080
```

**curl directly:**
```bash
curl -x http://127.0.0.1:8080 http://TARGET/
```

> [!warning] Proxying slows tools significantly
> Only proxy when you need to debug or capture the traffic. For high-volume fuzzing with `ffuf`, don't route through the proxy.
