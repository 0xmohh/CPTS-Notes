## Cheatsheet

### Directory Fuzzing
```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/directory-list-2.3-small.txt:FUZZ \
     -u http://target.htb/FUZZ
```

### File / Page Fuzzing (fixed extension)
```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/common.txt:FUZZ \
     -u http://target.htb/FUZZ.php
```

### Extension Fuzzing
```bash
ffuf -w ./extensions.txt:FUZZ -u http://target.htb/indexFUZZ
# extensions.txt contents: .php .bak .aspx .html .txt .zip .old
```

### Directory + Extension in One Pass
```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/common.txt:FUZZ \
     -u http://target.htb/FUZZ \
     -e .php,.html,.txt,.bak,.old,.zip
```

### Recursive Fuzzing
```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/raft-small-words.txt:FUZZ \
     -u http://target.htb/FUZZ \
     -recursion -recursion-depth 2 -e .php -v
```

### Subdomain Fuzzing (DNS)
```bash
ffuf -w /opt/useful/seclists/Discovery/DNS/subdomains-top1million-5000.txt:FUZZ \
     -u https://FUZZ.target.htb/
```

### VHost Fuzzing (Host header)
```bash
ffuf -w /opt/useful/seclists/Discovery/DNS/subdomains-top1million-5000.txt:FUZZ \
     -u http://target.htb/ \
     -H 'Host: FUZZ.target.htb' \
     -fs 900
```

### GET Parameter Name Discovery
```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/burp-parameter-names.txt:FUZZ \
     -u 'http://target.htb/admin.php?FUZZ=key' \
     -fs 0
```

### POST Parameter Name Discovery
```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/burp-parameter-names.txt:FUZZ \
     -u http://target.htb/admin.php \
     -X POST -d 'FUZZ=key' \
     -H 'Content-Type: application/x-www-form-urlencoded' \
     -fs 0
```

### Parameter Value Fuzzing
```bash
ffuf -w ./ids.txt:FUZZ \
     -u http://target.htb/admin.php \
     -X POST -d 'id=FUZZ' \
     -H 'Content-Type: application/x-www-form-urlencoded' \
     -fs 0
```

### LFI Discovery
```bash
ffuf -w /opt/useful/seclists/Fuzzing/LFI/LFI-Jhaddix.txt:FUZZ \
     -u 'http://target.htb/index.php?file=FUZZ' \
     -fs 1234
```

### Authenticated Fuzzing
```bash
ffuf -w wordlist.txt:FUZZ -u http://target.htb/admin/FUZZ \
     -b 'PHPSESSID=abc123; auth=admin' \
     -H 'Authorization: Bearer <token>'
```

### Multiple FUZZ Keywords
```bash
ffuf -w users.txt:USER -w passwords.txt:PASS \
     -u http://target.htb/login.php \
     -X POST -d 'username=USER&password=PASS' \
     -H 'Content-Type: application/x-www-form-urlencoded' \
     -mode clusterbomb \
     -fs 0
```

### Common Flags
```
-w FILE:KEYWORD        wordlist bound to a FUZZ keyword
-u URL                 target URL (place FUZZ anywhere)
-X METHOD              HTTP method (GET, POST, PUT, ...)
-d DATA                POST body (supports FUZZ)
-H "Header: val"       custom header (supports FUZZ)
-b "k=v; k2=v2"        cookies
-e .php,.bak           extensions appended to each word
-recursion             recurse into discovered directories
-recursion-depth N     max recursion depth
-t 40                  threads (default 40)
-p 0.1                 delay between requests (seconds)
-rate 50               max requests per second
-timeout 10            per-request timeout
-v                     verbose (full URL in output)
-c                     colored output
-s                     silent (results only)
-o FILE -of json       save output
-r                     follow redirects
-mode                  clusterbomb | pitchfork | sniper (default)
```

### Matchers (keep responses that match)
```
-mc 200,301,403        match status codes (default 200,204,301,302,307,401,403)
-ms 1234               match size
-ml 50                 match line count
-mw 200                match word count
-mr REGEX              match regex in response
```

### Filters (drop responses that match)
```
-fc 404,500            filter status codes
-fs 0                  filter size
-fl 10                 filter line count
-fw 200                filter word count
-fr REGEX              filter regex in response
```

## Checklist

### Pre-Flight
- [ ] Identify the web server (`whatweb`, `curl -I`) — informs extension choices
- [ ] Load a known-good page and note its response size, word count, line count — your baseline for filtering
- [ ] Send one request to a definitely-nonexistent path — note its response to filter out false 200s
- [ ] Pick the right wordlist for the scope (small for recon, medium for depth)

### Directory & File Discovery
- [ ] Fuzz top-level directories with a small list first (`common.txt`)
- [ ] Rerun with `-e` for extensions appropriate to the stack (`.php`, `.aspx`, `.jsp`, `.html`, `.bak`, `.old`, `.zip`)
- [ ] Enable `-recursion` once useful directories are found, cap depth with `-recursion-depth`
- [ ] Follow up interesting directories with file-specific wordlists (`raft-small-files.txt`)
- [ ] Look for backup/versioned files: `.bak`, `.old`, `.swp`, `~`, `.git/`

### Subdomain / VHost
- [ ] Fuzz subdomains via DNS (`-u https://FUZZ.target.htb/`)
- [ ] Always also fuzz vhosts (`-H 'Host: FUZZ.target.htb'`) — catches internal vhosts without DNS records
- [ ] Baseline vhost response size against a known-bad `Host` value
- [ ] Filter the baseline size with `-fs`
- [ ] Add discovered vhosts to `/etc/hosts` before browsing

### Parameter Fuzzing
- [ ] Try GET parameter names first — cheapest and most common
- [ ] Try POST parameter names with correct `Content-Type`
- [ ] Filter by exact size or word count of the "no parameter" response
- [ ] On a hit, pivot to value fuzzing with a type-appropriate wordlist
- [ ] Test JSON/XML bodies if the endpoint looks API-like

### Reading the Output
- [ ] Watch for "everything returns 200" — baseline a known-bad request and filter it out
- [ ] Watch for a flood of identical sizes — filter with `-fs`
- [ ] Watch for rate limiting (sudden 429s or connection resets) — back off with `-p` or `-rate`
- [ ] Rerun with `-v` once candidates narrow down — makes URLs easy to copy

### Authenticated Fuzzing
- [ ] Capture a valid session (`-b 'PHPSESSID=...'`)
- [ ] Verify the session is still valid mid-scan — re-auth if it expires
- [ ] Scope fuzzing to authenticated-only paths (`/admin/`, `/api/v1/`)

### Rate / Stealth
- [ ] Default `-t 40` is aggressive — lower to `-t 10` on fragile targets
- [ ] Use `-rate 20` to cap requests per second on monitored targets
- [ ] Use `-p 0.1-0.3` for a random delay window between requests
- [ ] On production assessments, coordinate rate with the client

### Output & Reporting
- [ ] Save results with `-o results.json -of json` for later parsing
- [ ] Keep one ffuf command per attack layer — easier to reproduce
- [ ] Note the exact wordlist and flags in your engagement log
