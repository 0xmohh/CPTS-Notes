## Cheatsheet

### WHOIS
```bash
whois TARGET.com
whois -h whois.cymru.com "-v IP"
```

### DNS Essentials
```bash
dig A TARGET.com
dig MX TARGET.com
dig TXT TARGET.com
dig NS TARGET.com
dig ANY TARGET.com
dig +short TXT _dmarc.TARGET.com

# zone transfer
for ns in $(dig +short NS TARGET.com); do dig axfr @$ns TARGET.com; done
```

### Subdomain Discovery (Passive)
```bash
# crt.sh
curl -s "https://crt.sh/?q=TARGET.com&output=json" | jq -r '.[].name_value' | sed 's/\*\.//g' | sort -u

# multi-tool
subfinder -d TARGET.com -silent
amass enum -passive -d TARGET.com
assetfinder --subs-only TARGET.com
```

### Subdomain Discovery (Active)
```bash
gobuster dns -d TARGET.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-110000.txt
puredns bruteforce subdomains.txt TARGET.com -r resolvers.txt
```

### vHost Fuzzing
```bash
ffuf -w wordlist.txt:FUZZ -u http://IP -H "Host: FUZZ.TARGET.com" -fs <baseline_size>
```

### Live Host Filtering
```bash
cat subs.txt | httpx -silent -status-code -title -tech-detect
cat subs.txt | httprobe
```

### Web Fingerprinting
```bash
curl -I http://TARGET
whatweb -a 3 http://TARGET
nikto -h http://TARGET -Tuning b
wafw00f http://TARGET
wappalyzer http://TARGET
```

### SSL Cert Inspection
```bash
openssl s_client -connect TARGET:443 -servername TARGET < /dev/null | openssl x509 -text
```

### Crawling
```bash
# gospider
gospider -s "https://TARGET.com" -d 3 -c 20 --other-source

# katana (handles JS)
katana -u https://TARGET.com -d 5 -js-crawl -jsluice

# hakrawler
echo "https://TARGET.com" | hakrawler -d 3 | sort -u

# historical URLs
echo "TARGET.com" | waybackurls | sort -u
```

### JS Mining
```bash
# extract JS URLs
katana -u https://TARGET.com -no-sandbox -silent -jc | grep "\.js$" > js-files.txt

# download
wget -i js-files.txt

# hunt for secrets
grep -r "api_key\|apikey\|secret\|token" .
grep -oP "https?://[^\"']+" .
```

### Robots.txt / Sitemap
```bash
curl https://TARGET.com/robots.txt
curl https://TARGET.com/sitemap.xml
```

### .well-known Enumeration
```bash
for path in security.txt openid-configuration oauth-authorization-server \
            assetlinks.json apple-app-site-association change-password \
            mta-sts.txt host-meta ai-plugin.json webfinger; do
  code=$(curl -s -o /dev/null -w "%{http_code}" https://TARGET.com/.well-known/$path)
  echo "$code  /.well-known/$path"
done
```

### Subdomain Takeover
```bash
subzy run --targets subdomains.txt
subjack -w subdomains.txt -t 100 -timeout 30 -ssl -c fingerprints.json
```

### Cloud Buckets
```bash
cloud_enum -k TARGET
cloud_enum -k target-dev -k target-prod -k target-staging
```

### Automated Recon
```bash
theHarvester -d TARGET.com -b all
python3 finalrecon.py --url https://TARGET.com --full
amass enum -active -brute -d TARGET.com -w wordlist.txt
```

### Nuclei Vulnerability Scan
```bash
# full pipeline
subfinder -d TARGET.com -silent | httpx -silent | nuclei -t nuclei-templates/ -silent

# specific templates
nuclei -u https://TARGET.com -t cves/ -silent
nuclei -u https://TARGET.com -t misconfiguration/ -silent
```

### Common TXT Record Patterns to Look For
```
v=spf1 include:_spf.google.com                 # Google Workspace
include:mailgun.org                            # Mailgun
MS=                                            # Microsoft 365
google-site-verification=                      # Google services
atlassian-domain-verification=                 # Jira/Confluence
docusign=                                      # DocuSign
stripe-verification=                           # Stripe payments
```

## Checklist

### Passive Recon
- [ ] WHOIS for registrant, contacts, nameservers
- [ ] Historical WHOIS via SecurityTrails/WhoisFreaks (if available)
- [ ] Query A, MX, NS, TXT, SOA records
- [ ] Query `_dmarc` for email policy
- [ ] Parse TXT records for third-party service hints
- [ ] Crt.sh for subdomains via certificates
- [ ] subfinder + amass passive
- [ ] Search engine dorks (site:*.TARGET.com)
- [ ] Dedupe subdomain list

### Active Recon — DNS
- [ ] Attempt AXFR against every nameserver
- [ ] DNS brute-force with wordlist
- [ ] Reverse DNS on any discovered netblock

### Active Recon — Web
- [ ] Confirm live subdomains with httpx
- [ ] Fingerprint each with whatweb/wappalyzer
- [ ] WAF detection with wafw00f
- [ ] Nikto scan (expect noise)
- [ ] vHost fuzzing with ffuf

### Content Discovery
- [ ] robots.txt
- [ ] sitemap.xml
- [ ] All `.well-known/` endpoints
- [ ] Crawl with katana or gospider
- [ ] Pull historical URLs from Wayback
- [ ] Extract and analyze all JS files
- [ ] Hunt for API endpoints, secrets in JS

### Cloud & Takeover
- [ ] cloud_enum for S3/Azure/GCS buckets
- [ ] subzy/subjack for subdomain takeover
- [ ] Try common cloud subdomain patterns

### Documentation
- [ ] List every live subdomain, status code, tech stack
- [ ] List every discovered email
- [ ] List every discovered API endpoint
- [ ] Map third-party services (Google, Atlassian, Stripe, etc.)
- [ ] Note any DMARC weakness for potential phishing
- [ ] Flag anything with known CVEs for exploitation phase
